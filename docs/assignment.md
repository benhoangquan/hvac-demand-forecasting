Context
In Quebec, energy consumption typically peaks daily in the morning, between 6 a.m. and 9 a.m., and in the evening, between 4 p.m. and 7 p.m. These periods, called peak periods, are particularly challenging to manage, especially during extreme weather conditions, whether very hot or very cold. To reduce these peaks, Hydro-Québec offers advantageous rates to encourage users to limit their consumption during these critical periods.

An effective method to reduce consumption during peak periods is to adjust heating or air conditioning, which represent the main sources of energy consumption in a building. Thanks to thermal inertia, it is possible to use energy before the peak period to preheat or precool the building while preserving occupant comfort. To optimize these strategies, it is necessary to predict, a few hours in advance, the consumption of the heating, ventilation, and air conditioning (HVAC) system. These predictions allow anticipating peaks and implementing proactive heating control rather than reactive control.

In this project, you must design a predictive model for energy consumption in a house located in
Montreal. You have access to one year of data containing the following features:
● Date
● HVAC system consumption (kW)
● Indoor temperature (°C)
● Weather data:
○ Outdoor temperature (°C)
○ Humidity (%)
○ Solar radiation (W/m²)
○ Wind speed (km/h)
○ Wind direction (°)
Using the method of your choice, develop a model to predict HVAC system consumption up to 4
hours (16 time steps) in advance.

## Project Structure

- `hvac_lstm_prototype.py`: Defines the core PyTorch `Dataset` and `LSTMModel`, plus the `create_sequences` utility function.
- `split_dataset.py`: Splits the raw training data chronologically into training and testing sets (e.g., 80/20 split).
- `train.py`: Loads the split data, preprocesses it (scaling), trains the LSTM model, evaluates it on the test split, and saves the trained model, scalers, and evaluation metrics/results.
- `predict_hvac.py`: Loads a pre-trained model and scalers, loads the competition test features (`test_features.csv`), generates predictions for `puissance_cvac_future` (16 steps ahead for each ID), and saves them in the required Kaggle submission format.
- `requirements.txt`: Lists Python dependencies.
- `dataset/`: Directory for data files (e.g., `train_dataset.csv`, `test_features.csv`, and the split files generated by `split_dataset.py`).
- `models/`: Directory where trained models and scalers are saved by `train.py`.
- `results/`: Directory where evaluation results (from `train.py`) and final submission predictions (from `predict_hvac.py`) are saved.

## Workflow

1.  **Install Dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

2.  **Prepare Data:**
    - Place the provided `train_dataset.csv` and `test_features.csv` into the `dataset/` directory.
    - Create the training/test split:
      ```bash
      python split_dataset.py
      ```
      This will generate `dataset/train_split.csv` and `dataset/test_split.csv`.

3.  **Train and Evaluate the Model:**

    ```bash
    python train.py --num_epochs 10 --batch_size 64 --hidden_size 64
    ```
    - This script reads from `dataset/train_split.csv` and `dataset/test_split.csv`.
    - It trains the model and prints epoch-wise training loss.
    - It evaluates the model on the test split and prints final metrics (MSE, MAE for the first prediction step).
    - It saves the trained model state (`lstm_hvac.pth`), feature scaler (`feature_scaler.save`), and target scaler (`target_scaler.save`) to the `models/` directory by default.
    - It saves evaluation results (`train_test_eval.csv`) to the `results/` directory.
    - You can customize hyperparameters and output paths using command-line arguments (see `python train.py -h`).

4.  **Generate Predictions for Submission:**

    ```bash
    python predict_hvac.py
    ```
    - This script loads the latest model and scalers from the `models/` directory.
    - It reads the competition test data from `dataset/test_features.csv`.
    - It generates the 16-step-ahead predictions for each ID.
    - It saves the predictions (`puissance_cvac_future`) in the Kaggle submission format (`ID,puissance_cvac_future`) to `results/submission.csv` by default.
    - You can customize input/output paths using command-line arguments (see `python predict_hvac.py -h`).

5.  **Submit to Kaggle:**
    - Upload the generated `results/submission.csv` file to the Kaggle competition.
